## Highlights

- **Project Rename (`ModelGate` → `PredGate` / `predgate`)**: Renamed across PyPI metadata, Python package (`src/predgate`), CLI (`predgate`), configuration (`predgate.yaml`), GitHub workflows (`.github/workflows/predgate.yml`), Docker Compose, React dashboard, and documentation because `modelgate` is already taken on PyPI (`0.2.0`). See [`MIGRATION.md`](../MIGRATION.md) for the full mapping table and temporary `MODELGATE_*` env-var fallbacks.
- **8-Check Quality Gate Suite**: Data contracts (Pandera), feature drift (PSI/KS), target leakage (`|r|` & univariate ROC-AUC), subgroup label shift (Holm-Bonferroni two-proportion z-test), slice regression (vectorized paired bootstrap CI), behavioral invariance/directional tests, latency/size/memory budgets, and algorithmic fairness.
- **Fail-Closed Champion Integrity**:
  - `.github/workflows/predgate.yml` and `action.yml` fail closed (`set -euo pipefail`) if `origin/${BASE_REF}` cannot be fetched or if the base-branch pinned SHA-256 is missing.
  - Installs the committed base-branch `predgate` archive (`git archive`) or an explicit pinned `predgate-spec` — never `pip install -e .` from the untrusted PR head — and verifies `champion/model.pkl` before running any PR data/training code.
  - Removed the custom workflow approval bypass; updates to `/champion/` and `/champion.dvc` are governed by GitHub Branch Protection + `.github/CODEOWNERS` (documented instructions for both personal `@<username>` and org `@<org>/<team>` accounts).
  - Removed silent retrain-on-pickle-failure and bare-pickle bypasses; corrupt pickles or missing manifests raise hard errors.
- **Interleaved Batched Median Latency Ratio Gate**: Replaces noisy `p95/p95` ratios with a paired bootstrap 95% CI on `median(candidate) / median(champion)` over interleaved batched samples (`max_latency_ratio=1.5`; `p95_latency_ms` optional). Deterministic injected-clock unit tests passed **5/5 consecutive `pytest` runs (110/110 tests, 91.2% coverage, 0 flakes)**.
- **Fairness Redesign & Per-Group Selection-Rate Shift**:
  - Champion-vs-candidate paired bootstrap gap CI (demographic parity, equal opportunity, equalized odds, per-group calibration) is the default gate; static absolute DP is opt-in (`enforce_absolute=True`) and evaluated relative to the champion's own gap.
  - Added Holm-Bonferroni–corrected two-sided paired bootstrap per-group selection-rate shift check at `WARN` level (`selection_rate_shift_warn=0.02`).
  - Emits 80%-power Minimum Detectable Effect (`MDE_DP`, `MDE_EO`) / insufficient-power notes in both PR Markdown comments and HTML reports.
- **Reproducible OpenML Benchmark Suite**: [`scripts/bench_public.py`](../scripts/bench_public.py) downloads Adult, German Credit, Bank Marketing (`1461`), and COMPAS (`42192`) from OpenML, runs all 4 frozen-threshold suites alongside stronger baselines (`Per-Group Acc Drop`, `Fixed DP >= 0.10`, and `Evidently 0.7.23` defaults), writes aggregate-only summaries to [`docs/benchmark_results.json`](benchmark_results.json), saves raw per-seed records to `release_artifacts/benchmark_per_seed_8467d37.json`, and generates [`docs/benchmark.md`](benchmark.md) strictly from JSON.

## Honest Limitations Table

All limitations below are directly observed in the frozen-threshold evaluation at commit `8467d37`:

| Area | Limitation / Observed Failure Mode | Empirical Evidence (`8467d37`) | Mitigation / Planned Follow-Up |
|---|---|---|---|
| **Slice Check False Positives on Benign Retrains** | `slices.py` triggers `FAIL` whenever `ci_upper > max_drop` (`0.03`), even when the point estimate is near `0.00` and the CI includes zero. On noisy or small test slices (e.g., German Credit `N_test=300`), benign hyperparameter or algorithm changes have wide CIs that breach `ci_upper > 0.03`. | **`184/540 (34.1%)`** FAIL on benign changes (`slices` check alone) and **`1/30 (3.3%)`** FAIL on held-out Bank Marketing `noop` (seed `7012`). | Scheduled for `v0.2.0`: gate `FAIL` on `ci_lower > 0` (statistically significant drop) + Holm-Bonferroni significance, reserving wide CIs that include zero for `WARN` or insufficient-power notes. |
| **Drift Check Hard-Fails on Any New Feature** | `drift.py` assigns `psi = 1.0` to any column in `train_df` absent from `reference_df`, causing an unconditional `FAIL` (`1.0 >= 0.25`) whenever a benign PR adds a new feature. | **`90/90 (100.0%)`** FAIL on `irrelevant_feature` benign trials (`90/540 = 16.7%` overall benign FAILs). | Scheduled for `v0.2.0`: emit a schema-addition `WARN` (or delegate to `data_contract`) instead of synthetic `psi = 1.0` hard `FAIL`. |
| **Benign Model-Family Swaps Trigger Budgets & Fairness Alerts** | Swapping GBM → Random Forest (`n_estimators=60`) legitimately increases single-row sklearn prediction latency >1.5x (triggering `budgets` FAIL) and shifts per-group decision boundaries (triggering `fairness` WARN alert fatigue). | `budgets`: **`87/90` FAIL, `3/90` WARN** on `algo_swap_rf` (`0/450` on all other benign changes). `fairness`: **`22/540 (4.1%)` FAIL, `93/540 (17.2%)` WARN** across all 540 benign trials. | Expected tradeoff for intentional model-family swaps; teams performing architecture migrations should review `WARN` diagnostics and explicitly update `max_latency_ratio` / champion baselines via CODEOWNERS-protected PRs. |
| **Weaker Than Evidently on Moderate Zero-Fill Training Drift** | PredGate's 10-bin equal-width PSI (`warn_at=0.10`, `fail_at=0.25`) can miss 40% null-to-zero spikes when zero falls inside an already-populated lowest bin, whereas Evidently's default Wasserstein/KS drift tests catch it reliably. | Held-out `silent_null_imputation`: PredGate **21/30 FAIL / 25/30 Flagged** on Bank Marketing and **27/30 FAIL / 29/30 Flagged** on COMPAS vs Evidently `0.7.23` **30/30** on both. | Scheduled for `v0.2.0`: use quantile-binned PSI or combine KS/Wasserstein p-value gating (with Holm-Bonferroni) alongside PSI. |
| **Rare-Event Threshold Shifts & Small-Group Statistical Power** | When baseline positive prediction rate is near zero (~0.2%) or protected groups are small (`n ~ 109–172`), threshold shifts produce tiny absolute rate changes below the 80%-power Minimum Detectable Effect (`MDE_DP = 0.066–0.148`). | Synthetic `fairness_threshold_shift_hi (τ=0.75)`: **0/30 (0.0%)**; Synthetic `τ=0.25`: **2/30 FAIL / 13/30 Flagged**; MDE low-power note emitted `30/30` on Adult, German, Bank, and COMPAS. | PredGate explicitly surfaces `minimum detectable gap / insufficient power` notes in PR comments and HTML reports rather than silently asserting fairness. |
| **Selection-Rate Shift Is WARN-Only** | Group-specific threshold shifts that *narrow* demographic parity (e.g., Adult `τ=0.25`, `DP: 0.167 → 0.102`) are caught primarily at `WARN` level (`28/30 WARN, 2/30 FAIL`), requiring human review rather than an automatic CI exit code 1. | Adult `τ=0.25`: **2/30 (6.7%) FAIL**, **30/30 (100.0%) Flagged** (`2F/28W`). | Intentional design to limit benign alert-fatigue blocks; teams requiring hard blocks on any selection-rate shift can treat `WARN` as blocking in CI. |
| **Binary Pickle Champion Serialization & Untrusted PR Training Code** | Champion baselines use `pickle` (verified by SHA-256 against the base branch, failing closed on corruption or Python/sklearn mismatch). Candidate training still executes PR code (`entrypoint`), so untrusted fork PRs should run with read-only `GITHUB_TOKEN` (standard `on: pull_request`) and without secrets. | Verified fail-closed in `tests/unit/test_security.py`; `skops` / ONNX serialization not yet supported. | Use `on: pull_request` (never `pull_request_target`) with branch protection requiring the `Run PredGate` check run and CODEOWNERS review on `/champion/`. |
| **No Live GitHub PR Demo Screenshots Yet** | End-to-end live GitHub PR runs (good branch, bad branch, fork PR) and screenshots of the PR comment, status check, and blocked merge are still pending. | `v0.1.0` git tag intentionally withheld per release policy. | Run scratch-repo PR demo and capture screenshots before creating tag `v0.1.0` and uploading `dist/*` to PyPI. |
| **Tabular Classification Focus** | Core checks (`fairness`, `label_shift`, `leakage` AUC, `slices` default F1) assume tabular binary classification (`sklearn`-compatible `predict` / `predict_proba`); multi-class, regression, NLP, and vision models are only partially supported. | Verified across 5 tabular binary datasets (Synthetic, Adult, German Credit, Bank Marketing, COMPAS). | Expand regression and multi-class check coverage in future minor releases. |
