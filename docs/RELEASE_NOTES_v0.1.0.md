## Highlights

- **Project Rename (`ModelGate` → `PredGate` / `predgate`)**: Renamed across PyPI metadata, Python package (`src/predgate`), CLI (`predgate`), configuration (`predgate.yaml`), GitHub workflows (`.github/workflows/predgate.yml`), Docker Compose, React dashboard, and documentation because `modelgate` is already taken on PyPI (`0.2.0`). See [`MIGRATION.md`](../MIGRATION.md) for the full mapping table and temporary `MODELGATE_*` env-var fallbacks.
- **8-Check Quality Gate Suite**: Data contracts (Pandera), shared-feature drift (reference-quantile PSI, KS, and numeric point-mass spike detection), target leakage (`|r|` & univariate ROC-AUC), subgroup label shift (Holm-Bonferroni two-proportion z-test), slice regression (paired bootstrap lower-bound CI gate with `inconclusive` interval width reporting), behavioral invariance/directional tests, latency/size/memory budgets, and algorithmic fairness.
- **Defect Fixes Validated on Fresh Seeds (`9000..9029`, Zero Post-Hoc Tuning)** (prior seeds `6000..6029` from commit `8467d37` treated strictly as a development set):
  - **Slice CI Gate (`slices.py`)**: `FAIL` only when the **lower bound** of the drop CI exceeds `max_drop` (`0.03`); `WARN` when the point drop exceeds `max_drop` but the interval includes values `<= max_drop`; marks intervals wider than `max_ci_width` (`0.10`) as `"inconclusive"` in check details, PR Markdown comments, and HTML reports. Reduced benign `slices` FAILs from **`184/540 (34.1%)`** → **`4/540 (0.7%)`** apples-to-apples (**`9/1350 = 0.7%`** across all 9 benign changes × 5 datasets) and eliminated the Bank Marketing `noop` FP (`1/30` → `0/30`).
  - **New-Feature Drift Handling (`drift.py`)**: Removed hardcoded `psi = 1.0` for columns absent from `reference_df`. New features are reported as `"new feature, no reference"` (configurable `on_new_feature: "info" | "warn"`, default `"info"`) while drift tests run on **shared features only**. Reduced benign `drift` FAILs from **`90/540 (16.7%)`** → **`0/540 (0.0%)`** (**`0/1350`** across all 5 datasets).
  - **Drift Sensitivity (`stats.py` & `drift.py`)**: Switched `compute_psi` to reference-quantile bins and added a numeric point-mass (value-spike) shift check (`point_mass_warn_delta=0.10`, `point_mass_fail_delta=0.20`). Raised `silent_null_imputation` detection to **`30/30 (100.0%)` FAIL on all 5 datasets** (Bank Marketing `21/30` → `30/30`; COMPAS `27/30` → `30/30`), matching Evidently `0.7.23` (`30/30`) with **`0/1350 (0.0%)`** benign drift FPs.
  - **Fairness Algo-Swap Metric Audit (`fairness.py`)**: On the `6000..6029` dev set (180 algo-swap trials), `calibration_gap_diff` triggered **0/19 FAILs and 0/74 WARNs** (FAILs were driven by `equalized_odds_diff` 16, `equal_opportunity_diff` 15, `demographic_parity_diff` 3; WARNs by `selection_rate_shift` 74, `demographic_parity_diff` 12). Because `calibration_gap_diff` is already anchored to ground-truth group base rates and uniquely catches probability-only miscalibration, it was retained as a full FAIL-eligible metric — confirmed out-of-sample on `9000..9029` (300 algo-swap trials across 5 datasets: **0/26 FAILs, 0/133 WARNs** from `calibration_gap_diff`).
- **Fail-Closed Champion Integrity**:
  - `.github/workflows/predgate.yml` and `action.yml` fail closed (`set -euo pipefail`) if `origin/${BASE_REF}` cannot be fetched or if the base-branch pinned SHA-256 is missing.
  - Installs the committed base-branch `predgate` archive (`git archive`) or an explicit pinned `predgate-spec` — never `pip install -e .` from the untrusted PR head — and verifies `champion/model.pkl` before running any PR data/training code.
  - Removed the custom workflow approval bypass; updates to `/champion/` and `/champion.dvc` are governed by GitHub Branch Protection + `.github/CODEOWNERS` (documented instructions for both personal `@<username>` and org `@<org>/<team>` accounts).
  - Removed silent retrain-on-pickle-failure and bare-pickle bypasses; corrupt pickles or missing manifests raise hard errors.
- **Interleaved Batched Median Latency Ratio Gate**: Paired bootstrap 95% CI on `median(candidate) / median(champion)` over interleaved batched samples (`max_latency_ratio=1.5`; `p95_latency_ms` optional) with deterministic injected-clock unit tests (114/114 unit tests passing, 91.39% coverage, 0 flakes).
- **Reproducible OpenML Benchmark Suite**: [`scripts/bench_public.py`](../scripts/bench_public.py) downloads Adult, German Credit, Bank Marketing (`1461`), and COMPAS (`42192`) from OpenML, separates quality findings from latency findings in benign tables, runs stronger baselines (`Per-Group Acc Drop`, `Fixed DP >= 0.10`, and `Evidently 0.7.23` defaults), writes aggregate-only summaries to [`docs/benchmark_results.json`](benchmark_results.json), saves raw per-seed records to `release_artifacts/benchmark_per_seed_9544988.json`, and generates [`docs/benchmark.md`](benchmark.md) strictly from JSON.

## Honest Limitations Table

All limitations below are directly observed in the frozen-threshold evaluation at commit `9544988` (fresh seeds `9000..9029`, zero post-hoc tuning):

| Area | Limitation / Observed Failure Mode | Empirical Evidence (`9544988`, seeds `9000..9029`) | Mitigation / Planned Follow-Up |
|---|---|---|---|
| **Low Power on Small-Sample Slice Regressions (`ci_lower > max_drop` Tradeoff)** | Requiring `ci_lower > max_drop` (`0.03`) eliminated benign `slices` false blocks (`34.1%` → `0.7%`), but on small test cohorts (e.g., German Credit `N_test=300`, `min_n=93` female rows) wide paired-bootstrap CIs prevent localized degradations from clearing `ci_lower > 0.03`. | German Credit `cohort_feature_corruption`: **5/30 (16.7%) FAIL / 12/30 (40.0%) Flagged** (vs Per-Group Acc Drop `28/30` and Evidently `20/30`). Bank Marketing `fairness_threshold_shift` full-suite FAIL dropped `21/30` → `14/30` (Flagged stayed `30/30`). | PredGate explicitly marks wide slice CIs (`width > max_ci_width=0.10`) as `inconclusive` in PR comments and HTML reports; teams with small test sets should increase held-out evaluation size or review `WARN` / `inconclusive` alerts. |
| **Benign Model-Family Swaps Still Trigger Quality & Latency Alerts** | Swapping GBDT → Random Forest (`n_estimators=60`) legitimately increases single-row sklearn latency >1.5× (triggering `budgets` FAIL) and shifts subgroup TPR/FPR and selection rates (triggering `fairness` FAIL/WARN alert fatigue); GBDT → Logistic Regression shifts subgroup selection rates on real datasets. | Across 300 algo-swap trials: `budgets` FAIL **`131/150` on RF** (`0/1200` on all other benign changes); `fairness` **`26/300 (8.7%)` FAIL** (`equal_opportunity_diff` 21, `equalized_odds_diff` 19, `demographic_parity_diff` 7; `calibration_gap_diff` 0) and **`133/300 (44.3%)` WARN** (`selection_rate_shift` 129). Overall Quality WARN-only across all 1,350 benign trials is **`230/1350 (17.0%)`**. | Expected tradeoff when changing model architecture; teams migrating model families should review `WARN` diagnostics and update `max_latency_ratio` / champion baselines via CODEOWNERS-protected PRs. |
| **Rare-Event Threshold Shifts & Small-Group Statistical Power** | When baseline positive prediction rate is near zero (~0.2%) or protected groups are small (`min_n = 93–594`), threshold shifts produce small absolute rate changes below the 80%-power Minimum Detectable Effect (`MDE_DP = 0.066–0.160`, `MDE_EO = 0.112–0.348`). | Synthetic `fairness_threshold_shift_hi (τ=0.75)`: **0/30 (0.0%)**; Synthetic `τ=0.25`: **4/30 FAIL / 9/30 Flagged**; German `τ=0.75`: **10/30 FAIL / 30/30 Flagged**; MDE low-power note emitted `30/30` on Adult, German, Bank, and COMPAS. | PredGate surfaces `minimum detectable gap / insufficient power` notes in PR comments and HTML reports rather than silently asserting fairness. |
| **Selection-Rate Shift Is WARN-Only** | Group-specific threshold shifts that *narrow* demographic parity (e.g., Adult `τ=0.25`, `DP: 0.164 → 0.094`; COMPAS `τ=0.25`, `DP: 0.267 → 0.243`) are caught primarily at `WARN` level rather than automatic CI exit code 1. | Standalone fairness `τ=0.25`: Adult **4/30 FAIL / 30/30 Flagged**, COMPAS **9/30 FAIL / 30/30 Flagged**, Bank **14/30 FAIL / 30/30 Flagged**. | Intentional design to limit benign alert-fatigue hard blocks (`129/300` algo swaps trigger selection-rate WARN); teams needing hard blocks on any selection-rate shift can treat `WARN` as blocking in CI. |
| **Binary Pickle Champion Serialization & Untrusted PR Training Code** | Champion baselines use `pickle` (verified by SHA-256 against the base branch, failing closed on corruption or Python/sklearn mismatch). Candidate training still executes PR code (`entrypoint`), so untrusted fork PRs must run with read-only `GITHUB_TOKEN` (standard `on: pull_request`) and without secrets. | Verified fail-closed in `tests/unit/test_security.py`; `skops` / ONNX serialization not yet supported. | Use `on: pull_request` (never `pull_request_target`) with branch protection requiring the `Run PredGate` check run and CODEOWNERS review on `/champion/`. |
| **No Live GitHub PR Demo Screenshots Yet** | End-to-end live GitHub PR runs (good branch, bad branch, fork PR) and screenshots of the PR comment, status check, and blocked merge are still pending. | `v0.1.0` git tag intentionally withheld per release policy. | Run scratch-repo PR demo and capture screenshots before creating tag `v0.1.0` and uploading `dist/*` to PyPI. |
| **Tabular Classification Focus** | Core checks (`fairness`, `label_shift`, `leakage` AUC, `slices` default F1) assume tabular binary classification (`sklearn`-compatible `predict` / `predict_proba`); multi-class, regression, NLP, and vision models are only partially supported. | Verified across 5 tabular binary datasets (Synthetic, Adult, German Credit, Bank Marketing, COMPAS). | Expand regression and multi-class check coverage in future minor releases. |
